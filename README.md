# arduino-led-and-2bit-binary-counter
My first Arduino project: LED circuit and 2-bit binary counter
Arduino LED Circuit & 2-Bit Binary Counter

This is one of my first hands-on projects using an Arduino UNO. I built a basic LED circuit and implemented a simple 2-bit binary counter using LEDs.

About the Project

This project helped me get started with Arduino hardware and understand how a simple digital logic concept can be implemented using physical components.

What I Practiced

- Arduino UNO basics
- Digital output
- LED interfacing
- Breadboard connections
- Basic binary counting
- Arduino programming and uploading code

Project Demonstration

This repository contains the Arduino source code, photos of the hardware setup, and a demonstration video of the working project.

Hardware Used

- Arduino UNO
- Breadboard
- LEDs
- Resistors
- Jumper wires

Repository Contents

- "code/" – Arduino source code
- "photos/" – Photos of the hardware setup and working circuit
- "video/" – Project demonstration video

Learning Outcome

Building this project gave me my first practical experience with Arduino and helped me understand the connection between programming, digital logic, and physical hardware.

This is a small but important step in my journey towards learning embedded systems and building more practical projects.
